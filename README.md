# 🌤️ Projeto Tempo

> Uma aplicação de previsão do tempo com interface moderna e responsiva. Veja as condições climáticas em tempo real!

## 🎯 Sobre

Uma aplicação web que exibe informações sobre o tempo e previsão climática. Desenvolvida com **HTML5, CSS3 e JavaScript puro**, oferece uma interface limpa e intuitiva para visualizar dados meteorológicos.

Perfeito para aprender consumo de APIs e manipulação de dados em tempo real.

## ✨ Funcionalidades

- 🌡️ **Temperatura em tempo real** - Dados atualizados constantemente
- 🌍 **Busca por localização** - Pesquise por cidades diferentes
- 🎨 **Interface responsiva** - Funciona em mobile, tablet e desktop
- 📊 **Previsão do tempo** - Veja a tendência climática
- 💨 **Informações detalhadas** - Umidade, vento, pressão atmosférica
- ⚡ **Carregamento rápido** - Performance otimizada

## 🛠️ Tecnologias

- **HTML5** - Estrutura semântica
- **CSS3** - Estilização moderna com Flexbox
- **JavaScript** - Lógica interativa e requisições
- **API de Clima** - Integração com serviço de previsão

## 📦 Como Usar

1. Clone o repositório:
```bash
git clone https://github.com/RafaelRibeiroSantos/projeto-tempo.git
cd projeto-tempo
```

2. Abra o `index.html` em seu navegador

3. Digite o nome de uma cidade na barra de busca

4. Veja as informações de tempo atualizadas automaticamente!

## 💡 O que Aprendi

- Consumo de APIs externas com JavaScript
- Manipulação assíncrona de dados (async/await)
- Tratamento de erros em requisições HTTP
- Manipulação dinâmica do DOM
- Estilização responsiva com CSS
- Boas práticas de UX/UI
